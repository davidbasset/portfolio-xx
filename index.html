03 — Proposition de valeur
Ce que j'apporte
A
Du code livrable, pas du code démo

Je travaille directement sur des bases de code en production — migrations critiques, refactorisations à risque, contextes legacy. J'ai transformé un simulateur Excel de 20 onglets en app Vue.js, migré un système de paiement complet, refondu une auth de zéro. Le genre de chantiers qu'on n'abandonne pas à mi-chemin.

B
Fullstack sans frontière artificielle

Je passe du composant Vue au microservice Node sans changer d'interlocuteur. Chez Shopopop j'interviens côté serveur sur des architectures distribuées. Chez TIBCO j'étais sur l'interface. Cette polyvalence réduit les frictions dans les petites équipes et les sprints tendus.

C
Freelance, mais pas solo dans sa tête

6 ans à m'intégrer dans des équipes produit — daily, code review, grooming, rédaction de specs JIRA. Je m'adapte aux process existants sans les ringardiser. Et quand c'est utile, je propose — mise en place de tests, refacto d'architecture, choix de stack.
